# Illustration assets

The 31 animal portraits, four layered world landscapes, and application icon were drawn specifically for Little Match Adventure as original SVG artwork. They are bundled locally and do not use emoji fonts, stock art, external asset services, or downloaded illustrations. PNG application icons are rendered from `icon.svg`.

Animal SVGs use a shared rounded portrait style with gradients, soft shadows, expressive faces, and distinct species silhouettes. Landscape SVGs are used for world cards and the corresponding game/map backgrounds.
