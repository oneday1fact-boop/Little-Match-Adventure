# Store artwork

- icon-512.png: 512 × 512 app icon.
- feature-graphic.png: 1024 × 500 PNG feature graphic, using original game illustrations.
- phone-01-home.png, phone-02-world.png, phone-03-game.png: 824 × 1784 PNG screenshots of the actual responsive game at 412 × 892 CSS pixels. No simulated scores or unlocked paid features are shown.

Phone screenshots were captured from the same bundled game UI in Chromium, rather than a physical Android screen. The Android bridge presence was simulated to hide the web-only install action; no native ad was requested. Replace these with final physical-device captures if Console review or your preferred listing requires them. Upload at least two phone screenshots; add actual tablet screenshots if distributing to tablets and Console requests them.

All artwork was produced from the repository's own game assets. No external stock imagery or emoji animal art is used.
